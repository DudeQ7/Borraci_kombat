# Borraci Kombat

Gra tworzona jako projekt zaliczeniowy w ramach przedmiotu **Programowanie Multimediów**.

## Informacje o projekcie

| Element | Wartość |
|---------|---------|
| Silnik  | Unity `6000.6.4f1` |
| Typ     | Gra (projekt zaliczeniowy) |

## Wymagania

- Unity Hub
- Unity Editor w wersji **6000.6.4f1** 

## Uruchomienie

1. Sklonuj repozytorium:
   ```bash
   git clone <adres-repozytorium>
   ```
2. Otwórz Unity Hub i wybierz **Add → Add project from disk**.
3. Wskaż folder sklonowanego projektu.
4. Otwórz projekt w Unity Editor w wersji `6000.6.4f1`.
